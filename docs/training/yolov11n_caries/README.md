# YOLO11n caries experiment

Этот каталог содержит результаты отдельного эксперимента object detection. Он не описывает и не оценивает классификатор, который используется веб-приложением DentalHelper.

## Состав

- `args.yaml` — очищенная конфигурация запуска без пути к датасету и устройства автора.
- `results.csv` и `results.png` — метрики и динамика 50 эпох.
- `Box*_curve.png` — precision, recall, F1 и PR-кривые.
- `confusion_matrix*.png` — матрицы ошибок.
- `labels*.jpg` — агрегированная статистика разметки без исходных изображений.
- `train_batch*.jpg`, `val_batch*.jpg` — визуальные материалы обучения и валидации.

Финальная строка `results.csv`: precision `0.63364`, recall `0.59851`, mAP@50 `0.59873`, mAP@50-95 `0.41432`.

## Исключенные артефакты

Веса `best.pt`, `last.pt`, базовые веса и исходный датасет не публикуются. Визуальные материалы обучения и валидации включены по подтверждению владельца проекта: данные взяты из открытых источников и могут использоваться в проекте. Перед повторным распространением набора данных необходимо сверяться с условиями его первоисточника.
