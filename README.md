# DentalHelper

Локальный MVP для первичной, не диагностической оценки фотографии зубов, поиска стоматологий и чтения рекомендаций по уходу.

> Результат модели носит информационный характер и не заменяет очный осмотр, диагностику или назначение врача-стоматолога.

## Локальный запуск

### Требования

- Python 3.10+ с зависимостями из `requirements.txt` и `web_api/requirements.txt`.
- Node.js 22.13+.
- [Ollama](https://ollama.com/) с локально загруженной моделью `llama3.1:8b-instruct-q5_K_M`.
- Стоматологические веса классификатора `best.pt`, полученные законным способом.

Поместите веса в `weights/best.pt`, `models/best.pt` или `yolo_models/dental_classifier5/weights/best.pt`. Для другого расположения создайте `.env` из `.env.example` и задайте `YOLO_MODEL_PATH`.

Запустите из корня проекта:

```bash
./run_local.sh
```

Сайт будет доступен по `http://localhost:5173`. Скрипт запускает локальные FastAPI, YOLO и Ollama-сервисы. Фотография используется только в пределах запроса и удаляется после ответа.

## Данные и внешние сервисы

Анализ изображения и генерация текстовой рекомендации выполняются локально. Для карты используются публичные сервисы OpenStreetMap: Nominatim получает введенный адрес, Overpass получает координаты для поиска клиник, а `tile.openstreetmap.org` отдает тайлы карты. Фотографии и результаты анализа этим сервисам не передаются.

## Обучение

В [docs/training/yolov11n_caries](docs/training/yolov11n_caries) опубликованы метрики и визуальные результаты отдельного эксперимента YOLO11n detector-модели. Владелец проекта подтвердил открытое происхождение клинических изображений и разрешение на их использование в проекте. Этот эксперимент не является моделью, используемой сайтом: сайт работает с локальным классификатором шести стоматологических классов. Веса и исходный датасет намеренно не публикуются.
