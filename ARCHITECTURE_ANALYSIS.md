# Архитектурный анализ DentalHelper

## Состав системы

DentalHelper — локальное веб-приложение с тремя слоями:

```text
Браузер (http://localhost:5173)
  -> React / Vinext / Vite (web/)
  -> FastAPI (127.0.0.1:8000, web_api/)
  -> YOLO-классификатор и локальная Ollama (agent/)
```

`web/vite.config.ts` проксирует `/api/*` на FastAPI. Это оставляет для пользователя один локальный адрес и не требует внешнего backend-хостинга.

## Основные модули

- `web/` — React-интерфейс: главная, проверка фото, карта клиник, статьи и политика обработки фото.
- `web_api/main.py` — API: проверка статуса, обработка изображения, геокодирование и поиск клиник.
- `web_api/clinic_search.py` — независимый поиск до семи ближайших стоматологий через Overpass с резервным Nominatim-поиском; расстояние вычисляется локально по формуле гаверсинуса.
- `agent/agent.py` — загрузка стоматологического YOLO-классификатора и генерация текстового пояснения через локальную Ollama.
- `run_local.sh` — единый локальный запуск Ollama, FastAPI и frontend.

## Поток анализа

`POST /api/analyze` принимает JPG, PNG или WEBP до 10 МБ, проверяет файл с Pillow и создает временный файл. YOLO возвращает наиболее вероятный класс и вероятности; Ollama получает только этот структурированный результат и формирует текстовое пояснение. Временный файл удаляется в `finally` после ответа или ошибки.

Модель ищется через `YOLO_MODEL_PATH` либо в стандартных локальных путях, включая `weights/best.pt`. Перед работой проверяется, что это классификатор с ожидаемыми шестью классами. Стандартная LLM — `llama3.1:8b-instruct-q5_K_M` на `127.0.0.1:11434`.

## Данные и ограничения

Изображения не сохраняются приложением и не передаются в картографические сервисы. Адреса и координаты для поиска клиник отправляются Nominatim и Overpass; отображение карты загружается с OpenStreetMap. Поэтому AI-анализ локален, а карта требует доступа к сети.

Сервис возвращает предварительную оценку, а не медицинский диагноз. Это ограничение должно сохраняться во всех пользовательских интерфейсах и материалах проекта.
